## 🎯 Brand Guidelines for Visuals

### Color Palette

- Primary: #7C3AED (Purple)
- Secondary: #10B981 (Green)
- Accent: #F59E0B (Orange)
- Neutral: #1F2937 (Dark Gray)
- Background: #F9FAFB (Light Gray)

### Typography

- Headers: Inter Bold
- Body: Inter Regular
- Code: Source Code Pro
- Accents: Space Grotesk

### Visual Style

- Modern, technical but approachable
- Clean backgrounds, avoid clutter
- Consistent icon style (Lucide icons)
- Subtle gradients and shadows
- High contrast for accessibility

## 📦 Asset Delivery Specifications

### File Organization

```
/media-kit/
  /images/
    /headshots/
    /screenshots/
    /infographics/
    /logos/
  /videos/
    /master-demo/
    /social-cuts/
    /b-roll/
  /templates/
    /social-media/
    /presentations/
```

### Naming Convention

`[asset-type]-[description]-[dimensions]-[version].[ext]`
Example: `screenshot-workflow-overview-1920x1080-v2.png`

### Delivery Formats

- **Images:** PNG (transparent), JPEG (photos), SVG (graphics)
- **Videos:** MP4 (H.264), MOV (ProRes for editing)
- **Documents:** PDF (print-ready), DOCX (editable)
