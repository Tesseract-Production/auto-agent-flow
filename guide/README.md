# Tesseract n8n Masterclass

This is the official website for the Tesseract n8n AI Orchestration Masterclass.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Supabase (auth & database)

## Features

- Modern landing page with micro-animations
- Course outline and curriculum
- Video previews
- Testimonials
- Pricing tiers
- Email capture with countdown timer
- Dark/light mode support
- Mobile responsive

## Environment Variables

Create a `.env.local` file:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```
